# Title
Raksha: Stop the scam before the OTP | YC Fall 2026 x Moss Demo

# Description
A scam call wins when someone stays frightened, isolated and on the line. Raksha gives them a moment to pause.

This demo shows the working Raksha app: a simulated digital-arrest call, evidence behind the warning, a trusted guardian sharing the same live context, a genuine call that stays safe, and a latency lab showing measured retrieval and network timings.

Recording note: Moss cloud credits were exhausted during the final rollout, so this video transparently demonstrates the offline detector. The app labels this mode, and the displayed fallback timings are not Moss benchmarks. Earlier hosted verification used real Moss and passed all 18 scripted scenarios.

Built with Next.js, TypeScript, WebSockets, Moss, Groq, Firebase Hosting and Google Cloud Run for the YC Fall 2026 x Moss Zero Latency Builder Sprint.

Moss powers in-process playbook retrieval, filtered live-call memory and optional community knowledge. Detection runs independently of the language-model coach.

The app is a prototype. Scripted evaluation results are not real-world accuracy guarantees. The demo does not intercept or disconnect cellular calls. Live speech availability depends on the browser.

Narration is AI-generated using OpenAI text to speech. Captions are included. Call scenarios use fictional people and scripted conversations.

Created by Shivam Gupta.
